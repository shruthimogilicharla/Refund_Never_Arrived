Refund Never Arrived · Audit Agent

A UPI payment fails but the money is debited. The app, the SMS and the refund worker all say "refund processed". This agent checks the bank statements as of the audit date, applies the RBI turnaround-time rules (T+1 person-to-person, T+5 merchant, ₹100 per late day) and decides what the bank still owes.
